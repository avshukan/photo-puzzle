# Iterations

This folder contains iteration plans and results.

## Purpose

Each iteration file documents:

- goal of the iteration
- selected scope (backlog items)
- release intent for the milestone, if relevant
- final result

This helps track how the project evolves over time.

An iteration file describes scope and outcome for the iteration itself. It does
not imply that the iteration must map to exactly one release; interim releases
may happen before the iteration is complete.

---

## Naming

Files follow the pattern:

```text
iter-01.md
iter-02.md
...
```
